**House rule:** read the first three, then decide if you want the later Earthsea. *Tehanu* is written for people who already know the earlier islands. *Tales from Earthsea* includes pieces that look backward; it is still not book one.

The Studio Ghibli film is a cousin that rearranges. It is not a table of contents.

## Common mistakes

- Starting with *Tehanu* because it is the “grown-up” one.
- Treating the first three as optional preamble.
- Using the Ghibli film as book one.
