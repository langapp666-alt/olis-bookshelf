King’s detective run splits in two for readers. This page is the **three Hodges books**. They are a complete trilogy. The later Holly novels assume you know how this partnership started.

If you want Holly’s full path, including *The Outsider* and *Never Flinch*, use the [Holly Gibney guide](/guides/holly-gibney-reading-order/). If you want a first King that is not a series, use the [starter path](/guides/stephen-king-starter-path/).

## Common mistakes

- Starting with *Holly* (2023) because the cover is a name you recognize from TV.
- Starting with *The Outsider* because the HBO series is easier to find.
- Reading *End of Watch* first because someone said the last one is “the King one.”
- Waiting for *Never Flinch* before opening *Mr. Mercedes*.

## FAQ

**Do I have to read all three?**  
If you want *End of Watch* to land, yes. *Mr. Mercedes* can stand alone as a first visit.

**Is Holly in all three?**  
She matters more as the books continue. Book one is still the door.

**Can I skip to The Outsider?**  
You can follow that case. You will not follow why Holly is expensive. Use the Holly page if you are skipping.

**TV first?**  
The show is a cousin. Start the novels at *Mr. Mercedes*.
