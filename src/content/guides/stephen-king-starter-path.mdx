  Do not start with a 70-book chronology. Do not start with *The Dark Tower* unless you already want a quest. *Misery* (1987), *11/22/63* (2011), and *The Shining* (1977) are three honest single-volume starts.

King’s catalogue is not a series. Treating it as one produces the worst kind of reading-order page: a fake spine and a spoiled reread. This is a **starter path** — a handful of complete books, then pointers to the actual series pages.

If you already know you want Roland, use [Dark Tower](/guides/dark-tower-reading-order/). If you want the detective run, use [Bill Hodges](/guides/bill-hodges-reading-order/) or [Holly](/guides/holly-gibney-reading-order/).

**House rule:** one book, finished, before you open a wiki. The “complete and uncut” *Stand* is still *The Stand*, not a different series. *Doctor Sleep* is a sequel to *The Shining*; read it after, if at all.

## Common mistakes

- Building a publication-order list of the entire career and calling it a reading order.
- Starting with *The Gunslinger* because it is “the big series.”
- Starting with *The Outsider* because of television.
- Reading *Doctor Sleep* first.
- Treating *Different Seasons* as four novels you must schedule.

## FAQ

**What is the best first Stephen King novel?**  
There isn’t one. *Misery*, *11/22/63*, and *The Shining* are three that do not require a chart.

**Should I read in publication order from Carrie?**  
Only if you like watching a career accumulate. It is not required and it is a long way to the books you actually meant to read.

**Do I need The Stand before Dark Tower?**  
No. See the Tower page.

**Complete and uncut Stand?**  
Same novel, longer text. Either is a standalone project.
