**House rule:** read the three. *Spectacular* is aftercare. OUABH is a different door you can open without these, but if you want both, Caraval first keeps the earlier sisters from arriving backward.

## Common mistakes

- Starting with *Finale*.
- Starting with OUABH and then calling *Caraval* optional filler.
- Treating *Spectacular* as book 4 of a required homework list.
