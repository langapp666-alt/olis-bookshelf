McFadden’s other thrillers are mostly one-book machines. This is the exception: three novels about the same woman, plus a later short that shops file as if it were a fourth novel.

The 2025 film uses the first book’s title. It is not a reason to open book three first.

**Contested placement, labeled:** story time puts *The Housemaid’s Wedding* after *The Housemaid’s Secret* and before *The Housemaid Is Watching*. Publication order puts the short last. McFadden has treated it as optional connective tissue, not as a required novel.

**House rule for a first read:**

1. *The Housemaid*
2. *The Housemaid’s Secret*
3. *The Housemaid Is Watching*
4. *The Housemaid’s Wedding* only if you want the gap filled

If you already have the short in hand after book two, you can read it before book three. You will not be “doing it wrong.” You also will not be missing a secret fourth novel if you skip it.

## Not the rest of McFadden

*The Locked Door*, *The Coworker*, *The Teacher*, *Never Lie*, and *The Inmate* are other books by the same author. They are not Housemaid 4–8. For a path through those standalones, use the [Freida McFadden thriller path](/guides/freida-mcfadden-thriller-path/).

## Common mistakes

- Starting with *The Housemaid Is Watching* because the cover looks like a new series.
- Treating *The Housemaid’s Wedding* as book one or as required homework.
- Buying *The Housemaid* movie tie-in and then opening a different McFadden title as “the sequel.”
- Assuming every McFadden workplace thriller shares Millie.

## FAQ

**Do I need the Wedding short?**  
No.

**Is the film a substitute for book one?**  
No. It is an adaptation of the first novel.

**Are the other McFadden bestsellers sequels?**  
Almost all of them are separate books. See the thriller-path guide.

**Which edition of The Housemaid?**  
Any complete printing, including later movie covers. Same book one.
