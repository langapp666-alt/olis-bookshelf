Garber has treated OUABH as a door you can open without the earlier three. **House rule:** start here if this is the title you came for. Read Caraval first only if you want the earlier sisters before you meet this cast. Do not start on book three of either series.

## Common mistakes

- Starting with *A Curse for True Love*.
- Treating Caraval book 3 as OUABH book 0 in a way that postpones this book one.
- Mixing the two trilogies into one six-book scramble.
