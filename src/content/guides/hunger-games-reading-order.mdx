**Contested order, labeled:** chronological charts put *Ballad*, then *Sunrise on the Reaping*, then *The Hunger Games*. That path hands you the Capitol’s earlier faces before Katniss earns them. It is a reread or a second visit.

**House rule:**

1. *The Hunger Games*
2. *Catching Fire*
3. *Mockingjay*
4. *The Ballad of Songbirds and Snakes* if you want more
5. *Sunrise on the Reaping* if you want more

You can read the two prequels in either order relative to each other after the trilogy. Publication order (*Ballad* then *Sunrise*) is the calmer path. Neither is a new book one.

## Common mistakes

- Starting with *Ballad* because the movie poster is in the shop window.
- Starting with *Sunrise on the Reaping* because it is the newest hardcover.
- Treating the prequels as required homework before book one.
- Searching “Hunger Games” and picking up a coloring book or official companion as novel 4.

## FAQ

**Do I need the prequels?**  
No. The trilogy ends.

**Should I read Ballad first because it is earlier?**  
Not for a first read.

**Is Sunrise on the Reaping a sequel to Mockingjay?**  
No. It is a later-published prequel.

**Movie order?**  
The original films follow the trilogy. The *Ballad* film is not an on-ramp to the novels.
