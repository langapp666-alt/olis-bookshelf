**Contested order, labeled:** chronological charts put *La Belle Sauvage* first. That path hands you Lyra’s earlier life before the trilogy earns it. **House rule:** *Northern Lights* → *Subtle Knife* → *Amber Spyglass*, then Dust if you want more.

*Lyra’s Oxford*, *Once Upon a Time in the North*, and *Serpentine* are extras. Optional after the trilogy. Not on-ramps.

The HBO / BBC series is a cousin. Show order is not a reason to start with Dust.

## Common mistakes

- Starting with *La Belle Sauvage* because it is “first.”
- Mixing US and UK titles and thinking *Golden Compass* is a different book one.
- Treating Dust as required homework before the trilogy.

4. **[Old Kingdom](/guides/old-kingdom-reading-order/) (Garth Nix)** — If you want another finished children’s-to-teen fantasy with a necromancer door and prequels that should stay later. Start at *Sabriel* (1995). *The Amber Spyglass* still closes the original three.
5. **[His Dark Materials, then Dust.]** If you want the second sequence as aftercare.
