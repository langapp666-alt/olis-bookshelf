The contested Foundation question is publication versus in-universe time. Chronological charts start with *Prelude* and *Forward the Foundation*. Those books were written for people who already knew the original arc.

**House rule:** original trilogy, then *Edge* and *Earth* if you want the 1980s continuation, then the prequels if you still want Hari’s earlier life. Chronological-first is a reread.

The wider “Asimov universe” charts that require *I, Robot* and the Empire novels before *Foundation* are optional connective tissue. They are not a Foundation on-ramp. *I, Robot* is a different door you can open later.

## Common mistakes

- Starting with *Prelude* because it is “first.”
- Using the TV show as a table of contents.
- Treating *Foundation and Earth* as optional filler you read first because of a cover.
- Waiting for a new streaming season before opening 1951.

## FAQ

**Publication or chronological?**  
Publication first. Prequels later.

**Is the TV show a substitute?**  
No.

**Do I need the robot novels?**  
No.
