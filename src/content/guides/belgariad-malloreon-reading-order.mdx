  It is book one of The Belgariad (1982). Then the four sequels, then the five Malloreon novels. *Belgarath the Sorcerer* and *Polgara the Sorceress* look like origins. They are written from after both quintets. Do not start there.

Two finished five-book runs, then two companion novels that spoil both endings. Chronology charts put Belgarath and Polgara first because they cover thousands of years before *Pawn*. That path is a reread map. Publication order is the first visit.

The Elenium / Tamuli is a different Eddings world. It is not Belgariad 13.

**Contested chrono, labeled:** both companions cover the deep past. Both assume you already know how the ten novels resolve. Belgarath first, then Polgara, if you want them at all.

**House rule:** Belgariad → Malloreon → companions optional. Stop after *Enchanters' End Game* if five books is enough.

## Common mistakes

- Starting with *Belgarath the Sorcerer* because it is “earlier.”
- Starting with *Guardians of the West* because a shop lists Malloreon as a separate series.
- Mixing in *The Diamond Throne* (Elenium) as Belgariad 6.
- Treating the two companion novels as required prequels.

## What to read next

1. **The Elenium is a different Eddings shelf.** Start *The Diamond Throne* only if you want Sparhawk, not Garion.
2. **[Shannara](/guides/shannara-reading-order/) (Terry Brooks)** — If you want another long Four Lands shelf where book one and the recommended door are not the same argument.
3. **[The Inheritance Cycle](/guides/inheritance-cycle-reading-order/) (Christopher Paolini)** — If you want a shorter finished quest four with a clear book one.
4. **[The Wheel of Time](/guides/wheel-of-time-reading-order/) (Robert Jordan)** — If the prophecy-and-farmboy shape was the hook and you want a longer climb.
5. **Stop after Enchanters' End Game.** The Belgariad five are a complete visit.

## FAQ

**Can I start with Belgarath?**  
Not for a first read. It spoils both quintets early.

**Do I need the Malloreon?**  
No. The Belgariad closes. The Malloreon is more of the same cast.

**Is the Elenium connected?**  
No. Different world. Either sequence first.

**Publication or chronological?**  
Publication for a first visit. Chronology only after you already know the endings.
