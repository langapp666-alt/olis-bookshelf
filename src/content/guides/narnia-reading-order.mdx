This is one of the clean contested orders in children’s books. Lewis later endorsed a chronological numbering for some editions. Publication order is still how the series was met, and it is how the wardrobe earns its own surprise.

## Chronological numbering (reread / boxed-set order)

Some modern sets number:

1. *The Magician’s Nephew*
2. *The Lion, the Witch and the Wardrobe*
3. *The Horse and His Boy*
4. *Prince Caspian*
5. *The Voyage of the Dawn Treader*
6. *The Silver Chair*
7. *The Last Battle*

**Contested order, labeled:** that path is coherent on a reread. For a first read it spoils how Narnia is *found*. **House rule:** publication order. *The Horse and His Boy* can move in story time; it still should not replace book one.

The various films are cousins. They are not a reason to start with Nephew.

## Common mistakes

- Opening a boxed set at *The Magician’s Nephew* because the spine says 1.
- Starting with *The Last Battle*.
- Treating *The Horse and His Boy* as optional filler you read first because it is “earlier.”

## FAQ

**Publication or chronological?**  
Publication first. Chronology is a reread.

**Did Lewis want Nephew first?**  
He was content for some later editions to number it that way. That does not make it the kindest first door.

**Which boxed set?**  
Whichever printing. Open *Wardrobe* first even if the box disagrees.
