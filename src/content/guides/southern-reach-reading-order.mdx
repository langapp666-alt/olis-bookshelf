**House rule:** read the three 2014 books. *Absolution* is optional aftercare that assumes you already have the Area. Do not start there because it is newest.

The Garland film adapts *Annihilation* and then stops being a trilogy map. Watch it after book one if you want; it will not replace *Authority*.

## Common mistakes

- Starting with *Absolution*.
- Treating the film as the whole Southern Reach.
- Reading *Acceptance* first because the title sounds like a conclusion you can sneak up on.

## FAQ

**Do I need Absolution?**  
No. The 2014 trilogy closes.

**Is the film a substitute?**  
For book one, partly. For the series, no.

**Can I read only Annihilation?**
