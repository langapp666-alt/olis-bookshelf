Penny’s site may list further collaborations or forthcoming titles beside the Gamache spine. If the book is not a Three Pines / Gamache novel, it is not a secret book one.

**Contested skip, labeled:** Penny says order is not essential for following a single crime plot. **House rule:** *Still Life* first. The personal stream deepens across the shelf.

## Common mistakes

- Buying *Dead Cold* and *A Fatal Grace* as two different book twos.
- Starting with *Bury Your Dead* or a later Quebec City-heavy title because a tour page featured it.
- Starting with *State of Terror* because Penny’s name is on the cover.
- Using the TV *Three Pines* episode order as the full novel table of contents.

## FAQ

**Do I need to read them in order?**  
Penny: not essential for the crime plot; recommended for the character arc. This house: *Still Life* first.

**Fatal Grace or Dead Cold?**  
Same book. US vs UK/Commonwealth title.

**Is State of Terror Gamache?**  
No.

**Where do I start if I watched the TV series?**  
Still *Still Life*. The show is a cousin.
