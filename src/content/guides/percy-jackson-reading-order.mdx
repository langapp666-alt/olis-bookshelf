**House rule:** read the original five. If you want more camp, Heroes of Olympus, then Trials of Apollo, then the senior-year books. The Disney+ show is a cousin of book one onward; it is not a reason to skip to *The Lost Hero*.

*The Sun and the Star* (with Mark Oshiro) is a Nico and Will novel. After the later cycles if you want it. Not an on-ramp.

Kane Chronicles and Magnus Chase can be read beside this shelf. They are not required and they are not secret Percy prequels. If you want only Greek/Roman camp, ignore them.

## Common mistakes

- Starting with *The Lost Hero* because the show mentioned Romans.
- Starting with *The Hidden Oracle*.
- Treating Kane Chronicles as Percy 6–8.
- Using the old films as a table of contents.

## FAQ

**Do I need all three cycles?**  
No. The original five end. Start at *The Lightning Thief* (2005).

**Chalice first because it is new Percy?**  
No.

**Kane Chronicles in the middle?**  
Optional parallel. Not required.
