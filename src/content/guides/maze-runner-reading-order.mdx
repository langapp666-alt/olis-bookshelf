Dashner wrote a complete trilogy, then two earlier novels, then a later-generation trilogy. Publication order and chronological order disagree. For a first read they should disagree. The original three are a mystery. The prequels spend that mystery.

**Contested order, labeled:** chronological charts put *The Kill Order*, then *The Fever Code*, then *The Maze Runner*. That path hands you the corporation and the virus before the Glade earns them. It is a reread or a second visit.

**House rule:**

1. *The Maze Runner*
2. *The Scorch Trials*
3. *The Death Cure*
4. *The Kill Order* if you want more
5. *The Fever Code* if you want more

You can read the two prequels in either order relative to each other after the trilogy. Publication order (*Kill Order* then *Fever Code*) is the calmer path. Neither is a new book one.

*Crank Palace* (2020) is a Newt novella that sits beside *The Death Cure*. Optional. Not Maze Runner 3.5 required homework. *The Maze Runner Files* is a companion, not a novel.

These three assume you already know what the first trilogy did to the world. They are not an on-ramp, and they are not a reason to skip *The Death Cure*.

Dashner’s site still treats the original Maze Runner novels and this later run as one shop window. They are not one numbered column.

## Common mistakes

- Starting with *The Kill Order* because a list called it book one.
- Starting with *The Fever Code* because Thomas is on the cover.
- Starting with *The Maze Cutter* because it is newer.
- Using the films as a table of contents for the prequels. The films do not carry those books.

## FAQ

**Do I need the prequels?**  
No. The trilogy ends.

**Should I read Kill Order first because it is earlier?**  
Not for a first read.

**Is Fever Code a sequel to The Death Cure?**  
No. It is a later-published prequel.

**Where does The Maze Cutter go?**  
After the original three, if you want the later generation. Not instead of book one.
