## Nine novels, one path

Four kingdoms, four couples. Andrews’s reading-order page lists them in one line. Publication order is the first-read path. Each new kingdom looks like a fresh series. It is not.

## The Ever Seas is not a hidden book one

*The Ever Seas* is the next generation. Andrews has said you *can* start there. This house does not. *The Ever King* spends parents you have not met.

*Night of Masks and Knives* is a later couple in the same war. A new cover is not a new series.

## The full Broken Kingdoms map

The nine-book table and the Ever Seas flag live on the [Broken Kingdoms reading-order guide](/guides/broken-kingdoms-reading-order/). This page is only which volume is actually first.

## FAQ

**Can I start with The Ever King?**  
Andrews allows it. This house does not. It spends people the nine novels introduce.

**Is each kingdom standalone?**  
Each has a new couple. The war is shared. Start at *Curse of Shadows and Thorns*.

**Do I need Ever Seas?**  
Not for the nine. It is the next generation.
