## Publication path for a first read

The contested Foundation question is publication versus in-universe time. Chronological charts start with *Prelude to Foundation* and *Forward the Foundation*. Those books were written for people who already knew the original arc.

**House rule:** *Foundation* (1951), then the original trilogy path as the guide tables it. Prequels later, or not at all, on a first pass.

## What the show is not

The Apple TV+ series is a cousin. It is not a license to start with a prequel novel, and it is not a substitute for the 1951 book.

## FAQ

**Should I read Prelude first?**  
Not for a first read. It is later-published earlier time.

**Publication or chronological?**  
Publication first. Chronology is a reread.

**Is the TV show book one?**  
No.
