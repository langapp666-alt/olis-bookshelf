## The published novels

Publication order is the only path: *Fourth Wing* (2023), *Iron Flame* (2023), *Onyx Storm* (2025). There is no chronological reshuffle. Untitled later novels are not an excuse to wait, and they are not hiding as a prequel.

*Fourth Wing* is the first novel. Empyrean is the series name. Searching either should get you to the same book one.

## What is not book four

*Threshing Day* is an Empyrean-related extra, not the next numbered novel. If a shop piles it next to *Fourth Wing* as “book 4,” that is retail gravity, not a table of contents. Read it after *Fourth Wing* if you want more Basgiath texture. Do not use it as an on-ramp.

A TV adaptation has been discussed. It is not a reading order.
