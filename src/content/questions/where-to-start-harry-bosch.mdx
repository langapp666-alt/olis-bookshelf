## Why a later cover looks like the start

Ballard shares the recent Bosch novels, so *The Waiting* looks like a new series. *The Lincoln Lawyer* has its own screen life. *The Late Show* is Renée Ballard’s actual book one. *The Poet* is Jack McEvoy, and *The Narrows* is its sequel. The TV show is a cousin with its own season order.

## What this house does

Bosch published order from *The Black Echo*. Read *The Poet* before *The Narrows*. Read *The Late Show* before *Dark Sacred Night* if you want Ballard’s introduction. Read *The Lincoln Lawyer* before the Haller novels, not instead of *The Black Echo*. Full lists on the [Harry Bosch reading-order guide](/guides/harry-bosch-reading-order/).

For another long run where publication order beats a chronology chart, see [Jack Reacher: publication or chronological?](/questions/jack-reacher-publication-or-chronological/).

## FAQ

**Can I start with The Lincoln Lawyer?**  
Only if you want Haller. It is not Bosch book one.

**Can I start with The Late Show?**  
Only if you want Ballard first. Bosch still starts at *The Black Echo*.

**Do I need The Poet?**  
Before *The Narrows*, yes.
