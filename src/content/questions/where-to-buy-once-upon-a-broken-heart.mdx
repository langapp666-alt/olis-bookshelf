## This trilogy's book one

*Once Upon a Broken Heart* (2021), then *The Ballad of Never After* (2022), then *A Curse for True Love* (2023). Publication order is the only path inside these three. There is no chronological reshuffle.

## Caraval is the other door

*Caraval* (2017) starts an earlier related series. Garber has treated this trilogy as a door you can open without those three. Read Caraval first only if you want the earlier sisters before this cast. Do not start on book three of either series. The earlier map is [Caraval](/guides/caraval-reading-order/).

## The full three

Mistakes and the Caraval note live on the [Once Upon a Broken Heart reading-order guide](/guides/once-upon-a-broken-heart-reading-order/). This page only names book one.

## FAQ

**Where to buy Once Upon a Broken Heart book 1?**  
*Once Upon a Broken Heart* (2021), Stephanie Garber. Not *A Curse for True Love*. Not *Caraval*.

**Do I need Caraval first?**  
No. It is an earlier series in a shared world. Start here if this is the title you came for.

**Is A Curse for True Love book one?**  
No. It closes the trilogy.
