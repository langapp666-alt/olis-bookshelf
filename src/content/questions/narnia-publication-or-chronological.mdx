## Why the wardrobe has to be found

Publication order is how the series was met, and it is how Narnia earns its own surprise: *Wardrobe*, *Prince Caspian*, *Dawn Treader*, *Silver Chair*, *The Horse and His Boy*, *The Magician’s Nephew*, *The Last Battle*.

*The Horse and His Boy* sits beside the first visit in story time. It still should not replace book one. Read it fifth on a first pass.

## What boxed sets are doing

Some modern sets number *The Magician’s Nephew* as 1, then *Wardrobe*, then *Horse*. Lewis later endorsed chronological numbering for some editions. That path is coherent on a reread. For a first read it spoils how Narnia is *found*.

The films are cousins. They are not a reason to start with Nephew. Do not start with *The Last Battle*.

## FAQ

**Publication or chronological?**  
Publication first. Chronology is a reread.

**Did Lewis want Nephew first?**  
He was content for some later editions to number it that way. That does not make it the kindest first door.

**Which boxed set?**  
Whichever printing. Open *Wardrobe* first even if the box disagrees.
